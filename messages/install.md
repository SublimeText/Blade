The package provides syntax definitions for Laravel Blade engine.

  It extends Sublime Text's HTML, CSS and JavaScript syntax.

Bug Reports:
------------

Before creating a bug report via https://github.com/SublimeText/Blade/issues/new,
please follow [Troubleshooting](https://github.com/SublimeText/Blade?tab=readme-ov-file#troubleshooting)
to make sure no out-dated override is causing issues.
